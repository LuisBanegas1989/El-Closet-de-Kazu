📦 Gestión de productos

📸 Cómo usar imágenes desde Google Drive:
  1. Sube tu imagen a Google Drive y haz clic derecho → "Obtener enlace".
  2. Asegúrate de que el acceso sea "Cualquier persona con el enlace".
  3. Copia el enlace (ej: https://drive.google.com/file/d/1uEpd4IzXgwCzfxwivCTzbM5_ViMPLjZY/view).
  4. El ID es la parte entre /d/ y /view.
  5. Pega el enlace en este formato:
    https://lh3.googleusercontent.com/d/TU_ID
✅ Ejemplo correcto:
https://lh3.googleusercontent.com/d/1uEpd4IzXgwCzfxwivCTzbM5_ViMPLjZY
❌ Ejemplo incorrecto (no funciona):
https://drive.google.com/file/d/1uEpd4IzXgwCzfxwivCTzbM5_ViMPLjZY/view
Usa el formato directo de Drive, o cualquier otra URL de imagen.
Escribe cada atributo en una línea, separando etiqueta y valor con dos puntos.
